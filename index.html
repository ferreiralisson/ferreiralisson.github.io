FUNDAMENTOS DE FRAMEWORKS

Mini Spring

Um framework web em Java para olhar por dentro da inversão de controle, da injeção de dependências e do roteamento HTTP.

  • Java
  • Jetty
  • Reflection
Ver código ↗
Decisões técnicas
Problema
Entender os mecanismos que conectam uma requisição HTTP à regra de negócio.
Decisão
Container próprio e injeção por construtor, com Jetty para HTTP e Jackson para JSON.
Trade-off
Implementar o container torna os fundamentos explícitos, mas exige cuidar de recursos que um framework pronto oferece.

APLICAÇÃO WEB

Ingresso

Marketplace de eventos, ofertas e pedidos. Backend e frontend independentes, conectados por contratos HTTP.

  • Java
  • Spring Boot
  • Angular
Ver código ↗
Decisões técnicas
Problema
Conectar eventos, ofertas e pedidos em uma aplicação web.
Decisão
API em camadas, frontend Angular independente e migrations com Flyway.
Trade-off
A separação permite evoluir as partes individualmente, mas exige manter os contratos HTTP compatíveis. Pagamentos e reembolsos são simulados.

MOBILE & INTELIGÊNCIA ARTIFICIAL

ChatIA

Uma conversa entre Flutter, Spring e IA local. Interface Cupertino integrada a uma API que gera respostas com Ollama.

  • Flutter
  • Java
  • Spring AI
  • Ollama
Ver código ↗
Decisões técnicas
Problema
Integrar uma interface mobile a um modelo de IA executado com Ollama.
Decisão
Flutter consome uma API Java com Spring AI. Cada resposta chega completa, sem streaming.
Trade-off
O fluxo de resposta é simples, mas a interface espera a geração terminar. O histórico fica na tela e não é enviado como contexto ao modelo.

APLICATIVO NATIVO · MACOS

Toca Desk

Uma interface nativa para explorar o armazenamento e acessar as ferramentas de manutenção do Mole CLI no Mac.

  • Swift
  • SwiftUI
  • AppKit
Ver código ↗
Decisões técnicas
Problema
Explorar o armazenamento e acessar ferramentas de manutenção do Mac por uma interface nativa.
Decisão
SwiftUI e AppKit integram consultas do sistema e sessões interativas com o Mole CLI.
Trade-off
A integração aproveita recursos do macOS, mas mantém o aplicativo específico dessa plataforma. O projeto é independente do Mole.
